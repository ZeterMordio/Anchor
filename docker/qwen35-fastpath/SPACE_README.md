# Anchor Qwen3.5 Fastpath

Prebuilt CUDA dependency image for dense Qwen3.5 SDPO HF Jobs.

Use this image ref from HF Jobs:

```text
hf.co/spaces/ZeterMordio/anchor-qwen35-fastpath
```

The default Space command runs a minimal HTTP server for the Space runtime.
Training jobs override the command.
